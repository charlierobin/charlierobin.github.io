Cinema 4D (C4D) Automatic Texture Updater & Reloader Plugin (+ Photoshop Save All)

A Cinema 4D 2023 (Mac-tested) plugin that acts as a simple live link between Photoshop and C4D, automatically reloading bitmap textures used in materials whenever they are saved by an external app. Paired with a Photoshop extension that adds a “Save All” command.

View Cinema 4D Texture Auto-Reloader on GitHub

Adobe Photoshop Auto-Save Script on Painting & Brush Strokes

A Photoshop Script Events Manager script that automatically saves the active document after brush strokes, adjustments, and layer changes—designed as an alternative workflow for live-updating textures in Cinema 4D.

View Photoshop Auto-Save Script on GitHub

Unity Input Manager Settings Editor

A Mac utility for browsing, copying, and editing Unity Input Manager asset files. Pretty much deprecated now that Unity has moved on to the new input system, though it got plenty of use in its day.

View Unity Input Manager Editor on GitHub

Utilities for Cleaning Out Old Unity Project Folders

Command-line tools (one in Python, one in Go) that scan local drives for Unity projects and clear out temporary folders like Library, Logs, and obj to free up disk space before archiving.
